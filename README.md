# Python-Projects
Exploratory data analysis for online store

# [Global Store Exploratory Data Analysis (EDA)](Exploratory_data_analysis_for_online_store.ipynb)

Цей репозиторій містить проєкт з розвідувального аналізу даних для міжнародної компанії, що реалізує продукцію у 45 країнах світу через офлайн та онлайн канали. 

## Мета проєкту
Очищення вихідних даних (обробка пропусків та аномалій), об'єднання розрізнених таблиць (events, products, countries) та пошук цінних бізнес-інсайтів щодо прибутковості товарних категорій, ефективності регіональних ринків та логістичних процесів.

## Використані технології
*   **Мова:** Python
*   **Бібліотеки:** Pandas, NumPy (Data Cleaning, Aggregation), Matplotlib/Seaborn (Data Visualization)

## Ключові бізнес-інсайти
*   **Фінансові показники:** Сумарний дохід склав понад 1.7 млрд г.од., при цьому чистий прибуток зафіксовано на рівні 501.4 млн г.од.
*   **Товарні категорії:** `Cosmetics` є абсолютним лідером за загальним прибутком, проте категорія `Clothes` демонструє найкращу рентабельність інвестицій (дохід втричі перевищує витрати). Найменш рентабельні категорії — `Meat` (націнка +16% до витрат) та `Fruits`.
*   **Географія та канали збуту:** Основним ринком є Південна Європа, а країною-лідером за прибутком — Андорра. Розподіл між офлайн- та онлайн-продажами є ідеально збалансованим (50.5% та 49.5% відповідно).
*   **Логістика:** Медіанний час відвантаження становить 25 днів. Найбільші логістичні затримки спостерігаються в Східній Європі (зокрема, Угорщині) та для категорії `Cereal`. 
*   **Кореляція:** Аналіз показав відсутність надійної закономірності між часом відвантаження та медіанним прибутком — тривале очікування не гарантує зростання доходу з транзакції.
*   **Часові тренди:** Пік прибутковості припадає на січень, а найактивнішим днем тижня для оформлення замовлень є п'ятниця.
